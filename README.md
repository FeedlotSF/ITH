https://feedlotsf.github.io/ITH/

Aplicación web de estrés calórico para ganadería. Muestra el ITH (Índice de Temperatura y Humedad) con corrección por radiación solar y viento, y recomienda si encender el riego.

Notificaciones push diarias a las 8:00 y entre las 10:00-11:00 (hora local del campo) con la proyección del día.
